关于 Personal AI

本地单机、单用户的受治理 agent 宿主——不是聊天壳。

它是什么

每条工具调用过治理链（deny / ask / allow 格，drift 即终止），每次文件变更留可逆回执，每个长跑任务是跨重启存活的 durable job，每次模型消费进预算账本。身体可换（pi / dsh），协议与治理不变。

现在能做什么
  • 会话——fork / rewind（可只回文件不动时间线）/ 跨会话搜索召回 / 导出 / 自动+手动压缩
  • 委派——delegate_task 起 durable 子任务：信箱双向 steer、预算切片、画像（model / effort / steering 隔离 / env 收窄 / 时长帽）
  • 治理——批准卡、项目信任门、命令白/黑名单、模式预设、操作员否决钩、秘密扫描、循环检测、错误连击升级
  • 上下文——repo_map 结构大纲、@文件、钉文件、steering / microagent 知识、记忆、旧会话限界读取
  • 自动化——durable 调度、写后 verify 反思环、spec 三件套、recipe / plan 库
  • 集成——MCP、LSP、浏览器工具、web 搜索/抓取、多提供方+自定义端点
有意不做（边界，不是缺漏）
  • 远程执行目标（SSH / WSL / Docker）——改写信任边界，等真实需求驱动
  • 脚本化编排 DAG / 多智能体 swarm——mailbox + task 树地基已备，编排面等拍板
  • OS 级沙箱 / marketplace / 多客户端挂载——与单机单用户定位冲突
  • 原生 PDF——模型无 document 模态时诚实降级为描述符，不假装看过
  • 双模型常驻编队 / LLM 判官审批——第二路常驻开销与政策敏感，裁定推迟
