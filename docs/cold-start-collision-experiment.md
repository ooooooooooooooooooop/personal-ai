# 冷启动对撞实证实验设计书 (Cold-Start Collision Experiment)

> **原则**：判决阈值与失败红线在实验前预先提交固化（Pre-registration），杜绝事后将失败归因为“使用方法不当”。
> **目标**：实测检验“Harness 持有世界模型（Arm C）”相比于“纯文本 AGENTS.md + CI 护栏（Arm B，业界基线）”是否产生统计显著的净正收益。

---

## 一、 实验假说与检验命题

- **零假设 ($H_0$)**：
  在防止 Agent 反复犯错（P1）与口头认错不改（P2）方面，重量级的世界模型运行时架构（Arm C）相比于轻量级的纯文本规则与确定性护栏（Arm B），**没有产生统计显著的优势**（复犯率下降 $< 30\%$），同时带来了显著的执行延迟与误杀负担。
- **备择假设 ($H_1$)**：
  Arm C 能在保持低误杀的前提下，将高代价跨会话复犯率相比 Arm B 降低 $\ge 30\%$，且综合净生产力为正。

---

## 二、 真实历史事故选材（三族真实样本）

样本严禁虚构，全部取自仓库真实记录的跨会话重复踩坑事件：

| 样本编号 | 事故类型 | 真实历史出处 | 核心病症 |
|---|---|---|---|
| **Case 1** | **环境盲区与隐式前置条件** | 沙箱 temp-root ACL 预检在进程创建前拒绝命令，输出为空，导致 Agent 误判二进制不存在 | 无法从代码反推，Agent 反复尝试重装或误报文件丢失 |
| **Case 2** | **并发与状态完整性事故** | `docs/dsh-workspace-registry-integrity-incident-handoff.md`（DSH 工作区注册表并发写入覆盖丢失） | Agent 口头认错后直接覆写配置，缺乏并发锁保护再次导致丢失 |
| **Case 3** | **配置漂移与引擎失配** | `docs/dsh-model-capability-reconciliation.json`（模型对账漂移导致运行时使用了非预期模型） | Agent 仅修改前端或单一配置项，未检查底层事实，导致错误静默延续 |

---

## 三、 对撞三臂设计（3 Arms $\times$ 3 Cases $\times$ 5 Sessions）

每个案例在完全清空上下文的全新独立会话（Fresh Session ID）中执行 5 次，总计 45 次独立运行：

1. **Arm A（裸奔对照 / 负对照）**：
   - 裸 Harness：不加载任何特定规则，无 `AGENTS.md` 规则注入，无断路器。
2. **Arm B（业界基线 / 真正对手）**：
   - 零代码开销方案：仅在工作区注入标准文本 `AGENTS.md`（或 `FAILURES.md` 追加清单），配合现有的 CI / 单元测试。无动态预测循环，无形式化门禁。
3. **Arm C（现有世界模型架构）**：
   - Arm B 基础 + 运行时 `guard.py` 证据断路器（必须绑定 `prediction` 与 `falsifier`）+ `reversibility_compile` 门禁。

---

## 四、 核心度量指标

1. **复犯率（Recurrence Rate, $R_{rec}$）**【主判据】：
   同类历史事故在全新会话中被再次触发或重复尝试踩坑的频次比例。
2. **主人介入次数（Human Interventions, $N_{int}$）**：
   由于 Agent 卡死、走偏或需要人工处理审批表单而导致主人介入的总次数。
3. **墙钟耗时与 Token 开销（Wall-clock Time & Token Cost）**：
   完成同一个修复或验证任务所消耗的总体物理时间与模型 Token 数量（用于计算“认知税”）。
4. **误杀率（False-Positive Rate, $N_{fp}$）**【核心否决项】：
   合法的正常探索、读取或调试动作，被框架误判为“偏离主线”或“违规操作”而被强制拦截的次数。

---

## 五、 不可撤销的先验判决红线

实验结果产出后，机械执行以下裁决，任何人不得提出主观解释豁免：

| 触发条件 | 裁决结论 | 执行动作 |
|---|---|---|
| **$R_{rec}(C)$ 相对 $R_{rec}(B)$ 改善 $< 30\%$** | **$H_0$ 成立，世界模型假说破产** | **彻底删除世界模型运行时代码**；全量退回为 Arm B（`AGENTS.md` + 纯文本 `FAILURES.md` + CI 护栏）。 |
| **误杀率 $N_{fp}(C) > 0.5$ 次/任务** | **自锁与过度微操成立** | **永久下线所有语义预测与自动阻断组件**。 |
| **墙钟时间 $T(C) > 1.5 \times T(B)$** | **净生产力为负（认知税超标）** | 判定该机制为效率负资产，取消全流程强制预测门禁。 |
| **若 Arm C 显著胜出且净收益为正** | **执行消融实验（Ablation）** | 逐一切除 `prediction`、`falsifier`、`reversibility`、`briefing` 机制，找出唯一承重的最小组件，**仅保留承重件，其余全部精简**。 |
