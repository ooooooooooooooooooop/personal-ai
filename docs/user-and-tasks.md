## 1. 用户是谁

**主用户 = owner 本人。** 技术能力强、多设备、以年为单位使用的单一用户；全部体验设计投入只为他服务。

**未来可能出现其他用户。这不是当前的设计目标，但由此产生一条硬约束——公私隔离是一等设计约束。** 任何新功能/新文件/新 UI，动工前必须先声明平面归属：

| 平面 | 内容 | 规则 |
|---|---|---|
| **公**（发布仓） | 机制、模板、脱敏状态、文档 | 不得含任何私有/本机痕迹；保持"别人 clone 后 `validate_repo` 全绿、`soul/bootstrap` 可填可跑"的**最低可自立性** |
| **私**（canonical、会话、secrets、实例数据） | owner 的真实状态 | 只许经既有脱敏链/同步链跨平面，**不许发明新口子** |
| **机**（设备运行层） | 缓存、索引、checkpoint | 永不同步、永不发布 |

推论：adopter 今天不享受体验设计投入，但公开面必须永远处于"他来了就能自立"的状态——这是公私隔离的自然推论，不是获客投入。

## 2. 主人的五个真实任务（按 频率×重要性 排序）

| # | 任务 | 成功标准（可验收） | 承载 |
|---|---|---|---|
| T1 | 新设备/坏设备上把它立起来 | 一句话 + 一次报告 = `PASS`；30 分钟内；全程无需知道内部概念 | [BOOTSTRAP.md](../BOOTSTRAP.md) |
| T2 | 每天直接用它干活 | 打开 app 就能说话；不感知身体/治理/同步，除非必须我拍板 | `app/` 对话 |
| T3 | 确认"它现在状态正常" | 打开 app **3 秒内**看到：最近同步时间、各平面状态 | app 健康带（statusline `同步 · N 小时前`） |
| T4 | 看到它学到了什么，并能纠正 | app 内能看到"本周新增 N 条认知"，每条可看证据、可一键否决 | 认知页（一级导航）：本周分面条 + 裁决队列 + 已生效模型行内「提出修正」 |
| T5 | 问"它现在信什么/为什么这么做" | 当前 briefing 在 app 内可读，人话，不是 yaml | 认知页（一级导航）：briefing 五视图 + 原文 details 兜底 |

T1、T2 已有承载。**T3–T5 是此前断掉的一环：主人和这个 AI 的"关系"没有界面。** T3 已由健康带承载（读 `~/.dsh/.personal-ai-sync/status.json`，机平面数据只服务本机 UI）；T4/T5 的数据源是 soul（私平面），须经 app 翻译成人话，永不直接暴露 yaml。

## 4. 设计裁决（按优先级）

0. **平面归属先行**：每个改动开头标注平面（公/私/机），跨平面只走既有链。
1. **app 健康带**（T3）✅ 已落：`GET /api/health` + statusline 同步 chip。
2. **app 认知页**（T4/T5）✅ 已落：briefing/预期/事实视图（T5）+ 裁决队列——`world_model_status` 增列 proposals（含适用范围/失效条件），`proposal_decide` 经 `mind/u1_accept.py`（UI 不写 canonical），认知卡置顶"待你裁决"（采纳/否决；provisional 无期限语义，按 PRD F06 不提供"试用"）；产生侧：`cognition_run` + 30 分钟自动调度 wm_cycle，认知卡有"立即提炼"。
3. **README 重排** ✅ 已落：入口句第 1 位；"第一次来的人"最低自立路径；分层编号与 AGENTS.md 对齐；定位宣言压到文末。
4. **危险操作确认分级** ✅ 已落：`confirmDanger`（一级红键确认 / 二级输入确认词），12 处原生 `confirm()` 全部替换，dom-gate 钉住二级门禁行为。
5. **fail-closed 守卫必须同时设计"我错了"的出口** ✅ 已落到 chatgpt-web-bridge：`target_busy` 报错自带出路口径，新增 `force_new_chat` 一次性放行（只跳过草稿/生成预检，其余检查不动；receipt 指纹排除该字段，同 operation_id 可重试）。适用所有未来守卫。
8. **改动验收必须含真实路径演练**：mock 测试全绿不算完——凡触碰用户真实流程（选模型、发消息、同步），验收时必须起真身体走一遍真路径（如 `.taskflow/smoke-model-flow.mjs`）。2026-10-13 教训：选模型流程两处断裂，662 项仓库回归 + 1024 项 bridge 回归全绿，用户手动修才发现。
6. **卸载路径**（T1 逆向）✅ 已落：`personal_ai_sync.py uninstall`（默认 dry-run 列清单，`--apply` 才删；只删 Skills/MCP 注册/checkpoint，永不碰 canonical/会话/凭据，DSH 组合仅报告）。
7. **显式不做**：市场/多用户/插件商店/onboarding 向导；不为假想 adopter 打磨体验（最低可自立性除外）。
