# Agent Harness Survey V1

Research track: what mainstream agent harnesses exist (2026-Q3) and how each is implemented.

- `inventory.md` — dated landscape census (deep-dive corpus + profiled-only + adjacent categories)
- `STUDY_TEMPLATE.md` — the 12-section template every per-harness study follows
- `harnesses/` — one implementation study per corpus harness
- `SURVEY_REPORT.md` — cross-harness synthesis (written last)
